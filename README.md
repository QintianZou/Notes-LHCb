# Notes-LHCb

A simple website to restore and browse your notes.

## Local use

Open `/home/runner/work/Notes-LHCb/Notes-LHCb/index.html` in a browser.

## Publish with GitHub Pages

1. Push this repository.
2. In GitHub, open **Settings → Pages**.
3. Set source to **Deploy from a branch** and select your default branch (`/root`).
4. Save and open the generated Pages URL.
